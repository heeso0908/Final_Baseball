## 🎯 프로젝트 주제

2025년 텍사스 레인저스는 실제 성적 기준 **81승 81패**를 기록했으나,  
득점과 실점을 기반으로 계산한 피타고리안 기대 승수는 **약 90.1승**으로 나타났습니다.

- 실제 성적: **81승 81패**
- 득점 / 실점: **684득점 / 605실점**
- 피타고리안 기대 승수: **90.1승**
- 실제 승수와 기대 승수의 차이: **-9.1승**

즉, 득실차만 놓고 보면 더 많은 승리를 거둘 수 있었던 팀이었지만,  
실제 결과는 기대치보다 낮게 나타났습니다.

본 프로젝트의 핵심 질문은 다음과 같습니다.

> **“2025년 텍사스 레인저스는 왜 피타고리안 기대 승수보다 실제 승수가 낮았을까?”**

이를 설명하기 위해 팀 레벨 지표, 접전 경기 성과, 불펜 운영, 타선 생산성, 수비 지표,  
머신러닝 기반 잔차 분석, Markov Chain & Monte Carlo Simulation,  
NSGA-II 기반 시나리오 최적화를 종합적으로 활용했습니다.

- 기대 승수 대비 실제 승수의 괴리, 즉 **잔차(Residual)** 를 설명하는 주요 요인 탐색

## 🧠 핵심 분석 흐름

### 1. 피타고리안 기대 승수 계산

득점과 실점을 기반으로 기대 승률을 계산했습니다.

```text
Expected W% = RS^1.83 / (RS^1.83 + RA^1.83)
```

2025년 텍사스 레인저스의 득점과 실점을 적용한 결과,  
기대 승률은 약 **0.556**, 기대 승수는 **90.1승**으로 계산되었습니다.

```text
Residual = Actual Wins - Pythagorean Wins
Residual = 81 - 90.1 = -9.1
```

잔차가 어디서 발생했는지 확인하기 위해 다음 관점에서 EDA를 진행했습니다.

- 월별 성적 흐름
- 홈/원정 성적
- 1점 차 경기 승률
- 접전 경기 성과
- 불펜 및 세이브 상황
- 타선 생산성
- 수비 지표
- 주요 선수별 성적 변화
- 투수 모션 분석

분석 결과, 텍사스는 평균 실점 억제 능력은 리그 상위권에 가까웠지만,  
**1점 차 경기와 세이브 상황에서 기대만큼 승리를 지키지 못한 구조**가 확인되었습니다.

### 3. 머신러닝 기반 잔차 분석

2015~2024년 MLB 팀 시즌 데이터를 활용해  
피타고리안 기대 승수 대비 실제 승수의 잔차를 설명하는 모델을 구축했습니다.  
단, 코로나 단축 시즌은 제외했습니다.

사용한 모델은 다음과 같습니다.

- Ridge Regression
- Lasso Regression
- Random Forest
- XGBoost

모델 검증 과정에서는 연도 기준 데이터 누수를 방지하기 위해  
**Group K-Fold**를 사용했습니다.

피처 중요도는 다음 방식으로 교차 검증했습니다.

- Permutation Importance
- SHAP
- 모델별 Feature Importance 비교

머신러닝 분석 결과, 잔차 설명에 큰 영향을 준 변수는 다음과 같았습니다.

| 주요 변수 | 의미 |
|---|---|
| `onerun_wp` | 1점 차 경기 승률 |
| `rs_per_g` | 경기당 득점 |
| `SV_pg` / `sv_pct` | 세이브 관련 지표 |
| `ERA` | 평균자책점 |
| `ir_pct` | 승계 주자 실점률 |

특히 **1점 차 경기 승률(`onerun_wp`)** 이 중요한 요인으로 나타났습니다.  
2025년 텍사스의 1점 차 경기 승률은 **42.0%** 로, 리그 평균 대비 낮은 수준이었습니다.

다만 머신러닝 모델은 과거 데이터 범위 안에서 현재 상태를 설명하는 데는 유용했지만,  
현재 텍사스 수치를 벗어난 극단적 개선 시나리오를 예측하는 데는 한계가 있었습니다.  
따라서 이후 단계에서는 시뮬레이션을 통해 가정 변화를 직접 반영했습니다.

---

### 4. Markov Chain & Monte Carlo Simulation

머신러닝 잔차 모델의 한계를 보완하기 위해  
타석 단위의 경기 흐름을 직접 재현하는 시뮬레이션을 설계했습니다.

시뮬레이션은 다음 두 방식을 결합했습니다.

#### Markov Chain

- 현재 상태를 **주자 상황 + 아웃카운트**로 정의
- 24가지 base-out state를 기반으로 상태 전이
- 단타, 2루타, 3루타, 홈런, 볼넷, 삼진 등 이벤트 발생 확률 적용
- 상태 변화에 따라 득점과 이닝 종료 여부 계산

#### Monte Carlo Simulation

- 162경기 시즌을 반복 시뮬레이션
- 여러 번 반복해 평균 승수와 불확실성 범위 확인
- Baseline 결과와 개선 시나리오 결과 비교

Baseline 검증 결과, 시뮬레이션은 텍사스의 팀 전력을 유사하게 구현했지만  
실제보다 평균적으로 더 높은 승수를 산출했습니다.

- 실제 승수: **81승**
- 시뮬레이션 평균 승수: **89.8승**
- 시뮬레이션 평균 득점 / 실점: **670.5득점 / 606실점**
- 실제 득점 / 실점: **684득점 / 605실점**

이는 팀의 기본 전력 자체보다, 실제 시즌 중 발생한 운영·상황 요인이  
잔차에 영향을 미쳤을 가능성을 보여줍니다.

---

### 5. NSGA-II 기반 시나리오 최적화

단일 시나리오만 비교하는 방식에서 벗어나,  
여러 개선 방향의 trade-off를 동시에 탐색하기 위해  
**NSGA-II(Non-dominated Sorting Genetic Algorithm II)** 를 활용했습니다.

최적화 목표는 다음 3가지입니다.

| 목적함수 | 방향 | 의미 |
|---|---|---|
| 승수(W) | 최대화 | 더 많은 승리를 만드는 조합 탐색 |
| 변화 크기(`σ_norm`) | 최소화 | 지나치게 비현실적인 가정 제외 |
| 실점(RA) | 최소화 | 수비 및 투수 운영 안정성 반영 |

시나리오는 12차원 σ 벡터를 기반으로 구성했습니다.

| 그룹 | 변수 예시 |
|---|---|
| 타자 | `hr_mult`, `bb_mult`, `k_mult`, `single_mult` |
| 마무리 투수 | `K_pct`, `BB_pct`, `BABIP`, `HR_pct` |
| 중간계투 | `K_pct` |
| 선발 투수 | `HR_pct` |
| 공통 | `team_K_pct_mult`, `team_BB_pct_mult` |

NSGA-II 결과, Pareto Front에서 다음 3가지 유형의 시나리오를 도출했습니다.

| 시나리오 | 설명 |
|---|---|
| Conservative | Baseline에 가까운 최소 변화 시나리오 |
| Balanced | 변화량과 승수 개선 효과의 균형이 좋은 권장 시나리오 |
| Aggressive | 승수 극대화에 가까우나 변화폭이 큰 시나리오 |

분석 결과, 단순히 한 지표만 개선하는 것보다  
**마무리 투수 안정화, 선발 피홈런 억제, 타선 생산성 보강**이 함께 이뤄질 때  
승수 개선 가능성이 커지는 것으로 나타났습니다.

## 🔍 주요 분석 결과

### 결론 1. 잔차의 핵심 위치는 접전 경기와 운영 구간에 있었다

시뮬레이션 내부 메커니즘으로 설명 가능한 차이는 제한적이었고,  
실제 -9.1승 전체를 완전히 설명하지는 못했습니다.

잔차는 다음 요소들이 함께 작용한 결과로 해석했습니다.

- High-Leverage 상황 약화
- BABIP 운 요소
- 마무리 교체 및 불펜 운영 변화
- 주전 선수 부상
- 코칭스태프 교체
- 시즌 전체의 운 요소

즉, 텍사스는 팀 전력 자체보다  
**접전 경기에서 승리로 연결하는 운영 효율이 낮았던 팀**으로 볼 수 있습니다.

---

### 결론 2. 현실적인 개선 방향은 불펜 안정화와 타선 생산성 보강이다

NSGA-II 시나리오 분석 결과, 다음 방향이 현실적인 개선안으로 도출되었습니다.

- 마무리 투수 보강 → 약 **2~3승 개선 효과 기대**
- 선발진 피홈런 허용 억제 → 여러 시나리오에서 일관된 효과
- 강타자 영입 및 타선 생산성 개선 → 저조한 공격 지표 보완

특히 선발 투수의 피홈런 억제는 다른 차원보다 더 큰 변화가 필요한 최우선 과제로 나타났습니다.

본 프로젝트는 2025년 텍사스 레인저스를 단순히  
“포스트시즌 진출에 실패한 팀”으로 보는 대신,  
**전력 대비 성과 효율이 낮았던 팀**으로 해석했습니다.

피타고리안 기대 승수와 실제 승수의 차이를 출발점으로 삼아,  
EDA와 머신러닝으로 원인을 탐색하고,  
시뮬레이션과 최적화를 통해 개선 가능성을 검토했습니다.

> “텍사스는 왜 기대보다 적게 이겼는가?”

**접전 경기 운영 안정화, 불펜 보강, 선발 피홈런 억제, 타선 생산성 개선**으로 정리할 수 있습니다.
